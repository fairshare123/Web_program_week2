WEEK 6 · TASK 2 · API INTEGRATION

API Explorer Hub

Welcome to my API Explorer! This project connects six different public APIs to create six mini-applications. Explore weather, currency exchange rates, trivia, dog images, Pokémon information, and random user profiles.

API 01 · OPEN-METEO

Weather Explorer

Get current weather information for a selected city.

Choose a city to see its weather.

API 02 · EXCHANGERATE-API

Currency Converter

Convert an amount using published exchange rates.

Your conversion will appear here.

API 03 · OPEN TRIVIA DB

Trivia Challenge

Answer a random multiple-choice question.

Click the button to start the trivia challenge.

API 04 · DOG CEO

Random Dog Gallery

Fetch a random dog picture from the Dog CEO API.

Your dog picture will appear here.

API 05 · POKEAPI

Pokémon Explorer

Search for a Pokémon to discover its type and stats.

Enter a Pokémon name to get started.

API 06 · RANDOM USER

Random Profile Generator

Generate a sample profile with a name, picture, email, and location.

Click the button to generate a sample profile.
